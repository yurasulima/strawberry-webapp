Cozy UI Sounds — 64 soft interface sounds for cozy games

Clicks, hovers, confirm and back, toggles and sliders, popups and panels, notifications,
success and error, dialogue text blips and rewards, with several variations of each so they
don't get repetitive.

Format: WAV, 44.1 kHz, 16-bit, mono, normalized to a similar loudness. Every file starts and
ends in silence, so they can be triggered back to back.
